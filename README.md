# Expense Tracker

A full-stack MERN application that helps users manage their personal finances by tracking income, expenses, and spending categories.

## 📖 Overview

Expense Tracker is a personal finance management application built with the MERN stack. Users can securely create an account, record transactions, organize expenses into categories, and monitor their financial activity through a clean and responsive interface.

## 🚀 Installation

### Clone Repository

```bash
git clone <repository-url>
cd expense-tracker
```

### Backend Setup

```bash
cd backend

npm install

npm run dev
```

### Frontend Setup

```bash
cd frontend

npm install

npm run dev
```

---

## 🔐 Environment Variables

Create a `.env` file inside the backend folder:

```env
PORT=5000

MONGO_URI=your_mongodb_connection_string

JWT_SECRET=your_jwt_secret

CLIENT_URL=http://localhost:5173
```
